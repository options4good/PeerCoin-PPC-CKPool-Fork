# PeerCoin-PPC-CKPool-Fork
CKPool to solo mine PeerCoin (PPC)<br><br>
I could not find a fork of CKPool that has the option to solo mine PPC, so I downloaded the original BTC version from BitBucket, modified some of the fies in the src directory and made it work. You can download the original version from BitBucket, replace the src directory with this one, compile, configure and solo mine PPC.
